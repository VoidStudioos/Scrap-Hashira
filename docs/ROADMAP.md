# Roadmap

Prioritize verified behavior over a claim that every website is supported.

1. Run the native suite on Windows and Linux full Chrome/Chromium; add CI with extension loading, real file confirmation, browser restart and repeated forced MV3 shutdown during every durable state.
2. Expand real-site adapter regression fixtures with user-authorized, sanitized examples. Add open shadow-root and same-origin-frame analysis, confidence calibration and better selector repair suggestions.
3. Add incremental capture for recycled virtual lists; distinguish page cursor state from URL pagination and preserve item history during scrolling.
4. Implement a streaming ZIP/file writer and export partitions, storage retention controls and validated large-job benchmarks.
5. Add manual same-origin redirect validation, improved image candidate ranking, per-product preferred originals, decoded-pixel budget checks and conditional resource revalidation.
6. Add importable profile editing for advanced pagination/gallery rules, better relative XPath generation and more localized diagnostics.
7. Add user-configured JSON endpoint field mappings, scoped accessible document formats and explicit endpoint-specific rate policies.
8. Replace/review the legacy SheetJS npm writer distribution before any untrusted workbook import; complete dependency/license and Web Store review.
9. Add optional local-only screenshot/vision assistance only if it materially improves unusual authorized layouts. No CAPTCHA bypass or fingerprint evasion is planned.
