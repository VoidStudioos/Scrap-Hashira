# تشخیص خودکار داده‌ها — نسخه ۰٫۲

افزونه پس از بررسی صفحه، نوع داده و رابطه بین بخش‌ها را از ساختار DOM، برچسب‌ها، ویژگی‌ها، درختواره و داده‌های موجود استنباط می‌کند؛ نیازی نیست قبل از هر بررسی همه فیلدها را دستی تعریف کنید.

| داده                  | رفتار                                                       |
| --------------------- | ----------------------------------------------------------- |
| کد فنی، شناسه و بارکد | متن اصلی حفظ می‌شود؛ صفر ابتدایی حذف نمی‌شود                |
| عدد                   | جدا از کد و با مقدار نرمال‌شده ثبت می‌شود                   |
| قیمت                  | با توجه به برچسب و واحد پول جدا می‌شود                      |
| موجودی و تعداد        | در فایل quantities قرار می‌گیرد                             |
| متن                   | متن اصلی، برچسب، مبدأ و دسته ثبت می‌شوند                    |
| درختواره              | شناسه، کد، عنوان، والد، مسیر و وضعیت باز/بسته ذخیره می‌شوند |
| عکس کلیکی             | تصویر کوچک، مقصد کلیک و نوع رابطه جدا ثبت می‌شوند           |

تشخیص کدهای عددی بدون برچسب همیشه قطعی نیست. مثلاً ۱۲۳۴۵ ممکن است کد یا تعداد باشد. موارد نامطمئن با دلیل و امتیاز اطمینان حفظ می‌شوند؛ کد دارای صفر ابتدایی به عدد تبدیل نمی‌شود. این قابلیت یادگیری ماشین یا OCR نیست.

## خروجی جدا برای هر دسته

داخل ZIP، پوشه `classification` شامل نوع‌بندی کلی و `tree.json` است. داخل `categories` برای هر دسته پوشه‌ای با نام/کد و شناسه پایدار ساخته می‌شود. فایل‌های `codes`، `numbers`، `prices`، `quantities`، `texts` و `links` در JSON و CSV جدا هستند؛ `records.json`، `images.json`، `clickable-image-links.json` و `index.html` نیز کنار آن‌ها هستند.

فایل `index.html` اصلی را باز کنید تا دسته‌ها را ببینید و وارد فهرست هر دسته شوید. لینک فایل تصویر ذخیره‌شده و لینک مقصد اصلی قابل کلیک هستند. تصاویر مشترک یک بار در پوشه تصاویر ذخیره می‌شوند و هر دسته به همان بایت‌ها ارجاع می‌دهد.

## عکس‌های کلیکی

- آدرس تصویر کوچک با مقصد کلیک یکی فرض نمی‌شود.
- لینک دارای پسوند تصویر یا ویژگی گالری/بزرگ‌نمایی، نامزد تصویر اصلی است.
- آدرس بدون پسوند هم اگر از گالری معرفی شده باشد بررسی می‌شود؛ نوع واقعی با امضای فایل و decode کنترل می‌شود.
- مقصد نامشخص تأییدشده تلقی نمی‌شود. برای فایل تأییدشده، خروجی وضعیت `verified-image` و لینک محلی ثبت می‌کند.
- دکمه جاوااسکریپتی بدون URL قابل دسترسی با وضعیت «نیازمند تعامل» گزارش می‌شود؛ افزونه آدرس پنهان را حدس نمی‌زند.

شاخه‌های بسته‌ای که فرزندانشان هنوز بارگذاری نشده‌اند گزارش می‌شوند؛ محتوای آن‌ها اختراع نمی‌شود. تشخیص کامل هر قالب یا هر سایت تضمین‌شده نیست و پیش‌نمایش برای اصلاح موارد نامطمئن باقی است.
